# 跑步配速計算器 (Pace Table Generator)

一個輕量、反應迅速的單頁靜態網頁工具，專為跑者設計。輸入 400 公尺田徑場單圈秒數，系統將即時自動換算 1 公里目標配速，並累計產生 5K、10K、半程馬拉松與全程馬拉松的完賽預估時間。

---

## 💡 功能特點

- **連續新增與對照**：支援多次輸入，自動以清單卡片形式向下（或向上）堆疊，方便對比不同秒數區間的完賽時間。
- **常用練習區間快捷鍵**：內建熱門的 400m 快捷按鈕（90s、98s、102s、108s、120s），點擊即可一鍵加入對照表。
- **本地資料儲存 (LocalStorage)**：自動將產生的配速表暫存於瀏覽器中，重新整理或重新開啟頁面資料不遺失。
- **一鍵匯出圖片**：內建 `html2canvas` 截圖功能，可直接把目前的配速對照表一鍵存成 PNG 圖片分享。
- **響應式與行動裝置優化**：針對手機螢幕進行卡片式排版優化，隨時隨地在跑道邊或備賽時皆可輕鬆操作。
- **零依賴與極致輕量**：採用純 HTML5 + Vanilla JS，並透過 Tailwind CSS 打造沈浸式暗色模式（Dark Mode）介面。
